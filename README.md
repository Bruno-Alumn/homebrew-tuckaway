# Homebrew tap for Tuckaway

[Tuckaway](https://github.com/Bruno-Alumn/Tuckaway) hides the menu bar icons you
don't need, without quitting the apps behind them. Install it with:

```sh
brew install --cask bruno-alumn/tuckaway/tuckaway
```

Tuckaway updates itself from new releases. The cask here comes from
`packaging/tuckaway.rb` in the main repository.
